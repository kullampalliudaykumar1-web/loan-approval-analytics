# 🏦 Loan Approval Analytics

## 📌 Project Overview

This project analyzes loan applications to identify patterns
associated with loan approval and rejection.

## 🎯 Objectives

- Understand applicant characteristics
- Clean and prepare the dataset
- Perform Exploratory Data Analysis
- Identify relationships between applicant features
- Perform statistical analysis
- Engineer meaningful features
- Generate business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Streamlit

## 📊 Dataset

Dataset: Loan Sanction Dataset

Rows: 614  
Columns: 13

## 🔍 Analysis Performed

- Data Cleaning
- Missing Value Analysis
- Duplicate Analysis
- Outlier Analysis
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Pivot Table Analysis
- Crosstab Analysis
- Correlation Analysis
- Statistical Testing
- Feature Engineering

## 💡 Key Insights

The analysis identifies important relationships between
applicant characteristics and loan approval status.
